# CASINO EDGE — カジノ理論トレーナー

https://yutoloto.github.io/casino-edge/

ブラックジャックとポーカーのセオリーを、電車で3分ずつ回して覚えるための単一HTMLアプリ。
スマホのChromeで開いて「⋮ → ホーム画面に追加」すると、アプリとして起動し圏外でも動く。

## なぜ独立リポジトリなのか

もともと `yutoloto/yx7k2p-tools` の `casino/` に置いていたが、
同リポジトリのルート（麻雀スコアアプリ）の manifest に `scope` が無く、
スコープが `/yx7k2p-tools/` 全体になっていた。その結果：

- カジノのURLがルートアプリのスコープ内に入る
- Android でリンクをタップすると**麻雀アプリの中で**カジノが開く
- Chrome の WebAPK 更新チェックが走り、**ホーム画面の麻雀アプリがカジノに置き換わった**（2026-09-13 実害）

`/casino-edge/` はルートアプリのスコープ外なので、この衝突が構造的に起きない。
オリジンは同じ `yutoloto.github.io` のままなので、**進捗（localStorage）は移行先でもそのまま使える**。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（約292KB・単一ファイル完結・外部依存なし） |
| `manifest.json` | PWA 定義。`scope` / `id` を `/casino-edge/` に明示 |
| `sw.js` | Service Worker。キャッシュ名は `casinoedge-`（旧 `casino-` と別名） |
| `icon-192.png` / `icon-512.png` | ホーム画面アイコン（maskable 対応・全面塗り） |

## 中身

- **3分セッション** — 12分野からタップ回答。正答率が低い分野ほど多く出る。不正解でタイマーが止まって解説
- ブラックジャック — ベーシックストラテジー完全表（S17/H17）、Hi-Lo、Illustrious 18 + Fab 4
- ポーカー — RFI（6-max / 9-max）、対レイズ15組、対3ベット8組、対4ベット、GTO、ICM
- **プッシュ/フォールド Nash 計算機** — 169×169 のプリフロップ全エクイティ行列を内蔵し、均衡をその場で計算
- その他のゲーム、ハウスエッジ総覧、カジノで働く側の知識、英語用語集

## 更新
